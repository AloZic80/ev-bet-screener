# Project memory: index

What is settled, in small files. Read the one you need; do not load them all.
`CLAUDE.md` holds only the rules needed in every session. `memory/history.md` is the full version-by-version record (search it by function name).

Status words: **active** (the rule now), **unverified** (believed, not confirmed at the source), **superseded** (kept for the record).
