## The strict matcher and the college switches (2026-11-28, Worker v3.94 / app v5.78)
- Owner 2026-11-28, on the Autopilot's game matching: "Both" (Shadow for college and tennis, and build the strict matcher).
- A Pinnacle game is tied to a Novig market in three steps, each with exactly one answer: (1) Novig's own list of who plays (`GET /v3/catalog/participants`, the league's open games within 20 minutes of the start): the game whose two competitors carry exactly Pinnacle's two team names (the whole name, or Novig's own short name; a tennis player may be written with a first initial); (2) that game's own markets (`GET /v3/catalog/markets?event=`) hold exactly one open two-way full-game moneyline (the market type carries no word for a part of the game, a set, a map, overtime, a draw or a three-way); (3) each outcome is tied to its team by Novig's own competitor id (the outcome's `subjectId`), or, when Novig sends no id, by a name that is exactly one of that competitor's own names (full name, short name, symbol) and none of the other's. An id and a name that contradict each other: nothing is matched. A name found inside another name is never a match, and nothing is matched by fitting the letters of a short code to a name.
- Why not codes: the first build of step 3 fitted a code's letters to a team's name. The independent review (2026-11-28) showed it swap the two sides when one team's code is not made from its own name and the other's fits both: Indiana "IU" against IU Indianapolis "IND", North Carolina "UNC" against UNC Wilmington "NC", Kentucky "UK" against UMKC "KC". It was never published.
- Real Novig shapes seen so far (the owner's "Test my books (raw)", 2026-11-28): a college moneyline's description is one team code ("OHIO"), its outcomes are codes ("OHIO" / "TOL"), the event says "Toledo @ Ohio"; the API description gives `MONEY` as the example market type. Novig's participants list has not been seen with real data yet: the Shadow list shows, for each game it could not match, what Novig lists (name / short name [symbol]).
- College football (NCAAF), college basketball (NCAAB) and college hockey (NCAAH) each have their own switch, starting in Shadow (KV `hf:leagues`; only the exact word `live` under the league's exact name lifts the hold). It can only hold a league back: a college game is placed only when its sport is Live AND its own switch is Live. A women's basketball league is never looked up in Novig's men's list.
- A game Novig has, whose market or sides the matcher refused, is shown as "On Novig, not matched" with its reason, and never teaches the Worker that Novig does not list that league.
- One look's outside calls (fetch plus Cache API, price lists cached), live v3.92 against v3.94: 3 games on Shadow 28 → 16; 6 games on Shadow 52 → 28 (37 → 23 when they start together); 3 games with 3 orders 47 → 44; 6 games with 3 orders 71 → 56.
